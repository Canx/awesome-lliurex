# Awesome Lliurex

Una lista curada de software, herramientas y recursos increíbles para el ecosistema Lliurex, con un enfoque en proyectos mantenidos por la comunidad.

Esta lista se actualiza automáticamente cada semana.

## Listas de Proyectos

Puedes explorar los proyectos de Lliurex de las siguientes maneras:

- **[Clasificación Alfabética](README_ALPHABETICAL.md)**: Todos los proyectos ordenados alfabéticamente.
- **[Clasificación Temporal](README_BY_DATE.md)**: Todos los proyectos ordenados por su fecha de última actualización.

## Cómo Contribuir

Este repositorio se actualiza automáticamente cada semana. Si creas un nuevo repositorio en GitHub relacionado con Lliurex, simplemente asegúrate de incluir en su nombre, descripción, README o topics alguna mención a "lliurex" para que sea detectado por nuestro proceso automático de búsqueda.

Los flujos de trabajo de GitHub Actions se encargan de actualizar el `projects.yaml` y las listas de proyectos automáticamente.
